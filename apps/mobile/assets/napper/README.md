# Supplied Napper resources

Saans Regular, Medium and Regular Italic and the activity WebPs were copied unchanged from
the user's `Archive.zip` (decoded Android resources) for this private parity implementation.
The full archive, executable bundles, account configuration and unrelated resources are excluded.

`*icon.webp` files are the full-size colored category symbols. `nap.webp` and
`nightwaking.webp` are the purple variants used in persistent timers. The additional baby, clock and settling-method images back functional drawer choices. Universal controls
continue to use vector icons. The separate on-device tracker keeps its existing line symbols.
